# DesiThali — Restaurant Ordering UI

This is a React + Vite + Tailwind frontend project. It was uploaded as a ZIP alongside the Thread & Thimble demo.

## Current GitHub folder status

The project configuration, Vite entry point and stylesheet are present. The original ZIP also contained `src/App.tsx`, but that main component has **not yet been added to this GitHub folder**. As a result, this extracted copy is incomplete and will not build until `src/App.tsx` is restored from the original upload.

## Original project run commands

Once `src/App.tsx` is restored, use Node.js 18 or newer:

```powershell
npm install
npm run dev
```

Vite normally prints a local URL such as `http://localhost:5173`.

## Demo login details from the uploaded README

- Customer: enter a name and table number 1–20.
- Manager: username `manager`, password `desi123`.

The project description indicates a customer ordering screen and a manager dashboard. The provided project uses browser local storage for order records; it does not include a separate production backend or real payment processing.
